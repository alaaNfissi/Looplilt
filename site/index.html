03 — YOUR TURN

Big possibility.
Small first step.

Start with a seed. Change a color, a shape, a moment. Your first film is only a few commands away.

Read the complete setup guide ↗

Node.js 22+ for HTML previews.
Video export adds Chromium and FFmpeg.

YOUR FIRST LOOP
git clone https://github.com/alaaNfissi/Looplilt.git
cd Looplilt
node bin/looplilt.mjs init my-film
node bin/looplilt.mjs build my-film --out my-film.html
↳

Open my-film.html in your browser.
Your little world is ready to play.

OR, START WITH A CONVERSATION

Give this prompt to a coding agent with file and terminal access. It will aim for a working HTML film first, then add video tools when you need them.

Installation details & compatibility ↗

No Looplilt account or API key. Your agent needs permission to work in your chosen folder.
