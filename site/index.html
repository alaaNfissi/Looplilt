A FEW GOOD QUESTIONS

Before your
first frame.

Can I try it without writing code?

Yes. Looplilt Studio lets you arrange video and audio, add shapes and text, animate layers, and export a film. For a smaller first step, the Pocket greenhouse remixer lets you change a finished animation’s colors, title and timing.

Does it work with every AI chat or agent?

Looplilt supports coding agents with file and terminal access, including Codex, Claude Code, Cursor, Gemini CLI, and GitHub Copilot CLI. Its local MCP server also exposes structured creation, editing and rendering tools to compatible MCP clients. Client configuration and permissions differ. A text-only chat can help write a scene, but cannot run the local tools by itself. Read the compatibility guide.

What does Looplilt actually make?

Looplilt creates editable 2D animation and video compositions. Studio combines shapes, text, imported media, motion, masks and audio in one project and exports MP4 or WebM. JavaScript films also keep their standalone HTML player and original source workflow.

Where do my project and files go?

Hosted Studio saves projects in your browser; download a portable .looplilt file to keep a copy with its media. The local companion saves ordinary files in the workspace you choose, so Studio and an agent can edit them together. There are no mandatory accounts or cloud media uploads.

Can I build on these examples?

Yes. The toolkit and original examples are MIT licensed. Keep the included license notices when redistributing the code. Your own additions remain yours.
