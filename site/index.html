BFROM YOUR TERMINAL

Four commands. A film.

Have Git and Node.js 22+? That’s all you need for your first HTML preview.

YOUR FIRST LOOP
git clone https://github.com/alaaNfissi/Looplilt.git
cd Looplilt
node bin/looplilt.mjs init my-film
node bin/looplilt.mjs build my-film --out my-film.html

Open my-film.html in your browser. Press play, turn on the sound, and meet your first little world.

A FEW GOOD QUESTIONS

Before your
first frame.

Can I try it without writing code?

Yes. The Pocket greenhouse remixer lets you change colors, a title, timing, and format in your browser. To create a different scene, edit the JavaScript or work with a coding agent using the setup prompt above.

Does it work with every AI chat or agent?

Looplilt works through local files and commands. Coding agents such as Codex, Claude Code, Cursor, Gemini CLI, and GitHub Copilot CLI provide those tools. Other agents can use it when their environment allows the same access. A text-only chat can help write the source; you still need a suitable environment to build and render it. Read the compatibility guide.

What does Looplilt actually make?

Looplilt draws animations from editable JavaScript. It builds a standalone HTML player, and can render an MP4 locally. The website’s remixer downloads a source project; MP4 export happens on your computer.

Where do my project and files go?

Remixer changes stay in your browser until you download them. Your local projects and video renders stay on your computer. Looplilt has no account system, uploads, or hosted rendering service.

Can I build on these examples?

Yes. The toolkit and original examples are MIT licensed. Keep the included license notices when redistributing the code. Your own additions remain yours.
