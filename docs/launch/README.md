The launch film, **A little idea**, is 26 seconds with original procedural sound. A restless dot becomes a flower, an orbit, and a kite. The code labels display values that drive the actual drawings. It is an editable Looplilt project, not a recording of an agent session.

## Finished launch renders

- [Wide film, 1280×720](media/little-idea-landscape.mp4) · [wide storyboard](media/little-idea-landscape.png)
- [Tall film, 720×1280](media/little-idea-portrait.mp4) · [tall storyboard](media/little-idea-portrait.png)
- [Encoded-file and audio measurements](media/launch-report.json) · [full browser playback results](media/launch-playback.json)

Both are 26 seconds at 30 fps. All 780 frames decode successfully. The wide and tall versions are composed independently, not cropped. The film ends on a clear invitation rather than pretending to be seamless. A separate shorter teaser would repeat the same idea without the story, so none is included.

The gallery adds six original stories, lasting 22–40 seconds: One More Light, The Missing Beat, Moonrise Express, Neon Relay, Ink Tide, and The Little Lift. Each has a wide and tall composition and a distinct stereo score. Their public media live in `site/media/`; the editable projects live in `examples/`. See the [capability tour](../showcase.md) and [quality report](QUALITY.md) for techniques, executed checks, and remaining limits.
