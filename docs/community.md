# Make something small. Share how it works.

The Looplilt showcase is a new initiative. No community gallery or testimonials are presented until independent submissions have been reviewed.

First prompt: **A small thing changes its mind.** Make a short original film, or remix a starter with a meaningful change. A working HTML preview is enough; an MP4 is welcome. Keep the editable source beside the result.

Use the [showcase issue form](https://github.com/alaaNfissi/Looplilt/issues/new?template=showcase.yml). Include a playable result, source, a sentence about what you changed, and any asset or audio credits. Submit only material you have permission to share. No email address, analytics identifier, or social account is required beyond the GitHub account used to submit.

The maintainer checks that the source builds, the result matches it, the stated credits are present, and the contributor explicitly permits a showcase link. Review third-party drawing code before running it. A submission is not automatically accepted, republished, or relicensed.

Accepted work can be linked in a small README gallery with the creator's chosen public credit and source link. Keep the creator's own licensing clear. Do not copy a film into the repository unless its author has specifically allowed that. Removal requests can be made on the same issue.

Start with one prompt and respond to real submissions. A monthly schedule, voting, prizes, and automated moderation can wait until there is sustained participation. There is no star requirement and no vote or follow exchange.
