# Make Room

An original 28-second kinetic typography film with a visual problem and payoff: a circle cannot fit into a rigid arrangement, so the arrangement changes. Letter blocks become gates, spacing becomes action, and a geometric flower closes the story.

Five named shots combine analytical springs, keyframes, a cubic motion path, transform hierarchies, responsive type, and original vector artwork. All motion evaluates from absolute time. The score combines a syncopated bass line, clipped piano chords, brass replies, plucked strings, a three-part drum arrangement, and a final sustained harmony. Eight named tracks make the arrangement editable.

Scene parameters expose the coral accent. Edit timing and type in draw.js; change musical phrases in project.json. Wide and tall compositions are authored independently within the same drawing.
