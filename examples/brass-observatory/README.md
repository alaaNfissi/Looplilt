# The Brass Observatory

32 seconds · Clockwork storybook · Original Canvas artwork and chamber score.

A small keeper finds the missing gear that lets an observatory answer a dark patch of sky. Five named shots move from a hillside to a telescope, a mechanism close-up, alignment, and a constellation reveal. This is a fictional visual story, not a physical telescope simulation.

The drawing uses local shot time, scoped transforms, keyframes, cubic paths, and pure-time motion. The score uses six named tracks, reusable motifs, shared visual/music cues, stereo placement, and a quiet ending. All visuals and sound are generated by Looplilt; there are no sampled recordings or pre-rendered clips.

Try `node bin/looplilt.mjs inspect examples/brass-observatory`, then `preview examples/brass-observatory`. Capture the mechanism with `frame examples/brass-observatory --scene repair --at 4 --out repair.png`. Render the complete film or add `--scene reply` for its ending. Use new output filenames.

Each shot exposes `accent` for its brass highlights. The final shot exposes `glow` (visually clamped to 0–2). Use a source-hash-checked revision to change that ending without editing other shots. Landscape, portrait, and square compositions share the same source.
